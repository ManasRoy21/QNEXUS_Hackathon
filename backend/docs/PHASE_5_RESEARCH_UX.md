# Phase 5 — Visualization & Research UX

## Design & Visualization Invariants
1. **Defensible Semantic Statuses**:
   - `QUANTITATIVE`: Backed by closed-form analytical physics formulas.
   - `QUALITATIVE`: Structured narrative explanations without full physics numerical models.
   - `UNIMPLEMENTED` / `SIMULATION_MODEL_NOT_AVAILABLE`: Explicitly declared without silent fallback to clean.
2. **Empirical Visualization**:
   - QBER vs Distance (km)
   - QBER_obs vs Intensity (γ)
   - Forgery bound ε₁ vs Distance / Pulse count
   - Repudiation bound ε₂ vs Threshold gap (Tv - Ta - Δ)
3. **Mathematical Transparency**:
   - Formula display (LaTeX notation)
   - Parameter inputs
   - Step-by-step intermediate calculations
   - Plain-language scientific interpretation
